# Solana Trading Bot Clone

A high-performance Telegram UI clone for Solana trading.

## Setup Instructions
1. **Get a Bot Token:** Message @BotFather on Telegram.
2. **Environment Variables:** Create a `.env` file or set in Render:
   - `BOT_TOKEN`: Your Telegram Token.
   - `PORT`: 8080 (Render provides this automatically).
3. **Local Run:** ```bash
   pip install -r requirements.txt
   python bot.py
